Scenario loop: live → when the signal is not good enough, the last value is held briefly → the display pauses and asks the user to adjust → measurement resumes once conditions recover. While paused the trace is not drawn at all, because a flat line could be mistaken for a stopped heart: the sweep stops, only the grid remains, and the instruction is shown large and centered. On recovery the sweep restarts from the left.情境循環：即時量測 → 訊號不夠好時短暫保留上一個數值 → 畫面暫停並請使用者調整 → 條件恢復後重新量測。暫停時完全不畫波形，因為一條平線可能被誤認為心跳停止：掃描停止、只留格線，指示以大字置中顯示。恢復後掃描從左側重新開始。

Display principles顯示原則
  • Never fake a signal. When the measurement is unavailable the number becomes “—” and nothing is drawn.絕不假造訊號。無法量測時數字顯示為「—」，也不畫任何波形。
  • Show uncertainty honestly. A held value is faded; it is never presented as fresh.誠實呈現不確定性。保留中的數值會變淡，絕不假裝是最新的。
  • Tell the user what to do, not what went wrong. Instructions are short, actionable and centered on the panel.告訴使用者該做什麼，而不是哪裡出錯。指示簡短、可執行，並置中顯示在畫面上。
  • Report from valid data only. The session mean ignores windows that could not be measured, and says so.只用有效資料做報告。平均值會排除無法量測的時段，並明確說明。
